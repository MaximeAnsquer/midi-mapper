Entrées

Les entrées cochées sont écoutées. Chaque règle peut aussi se limiter à une entrée précise.

Sortie par défaut

Chaque sortie d'une règle peut viser un autre port. Sur Mac, pour envoyer vers un logiciel (DAW…), active le bus IAC dans Configuration audio et MIDI.

Réglages

Note 60 (do central)

Configurations

La configuration en cours est enregistrée automatiquement dans ce navigateur.

Règles de conversion

Chaque message reçu est comparé aux règles, de haut en bas. Toutes les règles qui correspondent s'appliquent (sauf si l'une d'elles « arrête » la suite) et chacune peut envoyer un ou plusieurs messages. Utilise Apprendre pour remplir une condition en jouant simplement le message.
